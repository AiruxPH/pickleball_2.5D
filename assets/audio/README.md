# Audio Assets Placeholder

Place your audio files here in `assets/audio/`:

| Filename         | Description              |
|-----------------|--------------------------|
| hit.mp3          | Paddle hitting ball      |
| bounce.mp3       | Ball bouncing on floor   |
| net_hit.mp3      | Ball hitting the net     |
| button_click.mp3 | UI button press sound    |
| crowd_cheer.mp3  | Crowd cheer on point     |
| victory.mp3      | Match win jingle         |
| defeat.mp3       | Match lose sound         |
| background.mp3   | Ambient loop (crowd/music)|

Once files are placed here, uncomment the FlameAudio lines in:
  lib/services/audio_service.dart

Free sources:
- https://freesound.org (search "pickleball", "tennis hit", "ball bounce")
- https://pixabay.com/sound-effects/
